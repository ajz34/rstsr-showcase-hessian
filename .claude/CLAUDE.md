# Prototype Implementation for Rust-based Hybrid Functional Second Derivatives Program

## Local settings

As human developer, you should also provide @CLAUDE.local.md to specify some local directories and environment variables.

## Language selection

- For jupyter notebook markdown cells, we will allow use Chinese.
- For other cases (python/rust code, or jupyter notebook code cells), we will only use English.

## Python part

You should already able to use `pyscf`, `numpy` and `scipy` in the Python part. You can run python scripts and jupyter notebooks.
