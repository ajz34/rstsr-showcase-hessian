# 请求 AI 总结工作纪要：简易版本 RHF Hessian 实现的流程与细节

该项目是用于原型实现电子结构自洽场方法的 Hessian。
目标尽管是 Rust 语言，但我们先用 Python 打一遍草稿。

## 工作纪要目标

目前，我们原型实现了 RI-RHF 方法的 Hessian。
你的目标，是总结我们在实现过程中，所经历的流程与细节。并且在未来实现 RI-UHF 以及 DFT 方法的 Hessian 时作为参考：你将来会用到这里生成的总结来实现这些功能。

## 当前工作的大致流程

下述文件是依照时间顺序编写的。未来开展其他方法的实现时，一般来说也将遵循类似的流程。

- prototype/00-ref_moles.ipynb：先计算了一些 Hessian 参考数据，作为后续分解的对比。该文档执行时间很长，不应该再执行一次。
- prototype/nh3_r_hf.npz：该文件储存了所有重要的起始数据与最终结果 (mo_coeff, mo_occ, de_ref 等)。
- prototype/01*.ipynb, 02*.ipynb：**自上而下**实现了 Hessian 的分解。程序越简洁越好；在复杂张量缩并的地方全部尽可能使用 einsum，以帮助理解与未来的优化。
  这里的程序参考 PySCF 源码 (hessian/rhf.py, df/hessian/rhf.py)，但具体细节差异是比较大的。
- prototype/nh3_r_hf_decomp.npz：该文件储存了分解后的 Hessian 结果与一些重要的中间变量，可以用于程序的调试与结果正确性验证。
- pyhessref/：该目录下的代码是我们自己**自下而上**实现的 Hessian 计算程序。该程序基本上是分解后的 ipynb 的重新实现，但在工程上更规范，且被充分测试。这里的实现与 PySCF 的细节接近、但框架差异较大；未来也需要以此为模板实现到 Rust 程序中。
